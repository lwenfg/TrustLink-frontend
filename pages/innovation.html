作品介绍 创新点

从端点到路径的连续安全链

TrustLink 的论文创新不在于并列堆放密码算法，而在于将无人系统任务中的端点可信、身份认证、会话密钥、载荷数据与转发路径，组织为按依赖关系推进的一条安全链。

端点可信TEE 认证流程
身份已认证SRP-PAKE
密钥端到端X3DH 协商
载荷可验证加密、认证、防重放
路径最小知情VRF + AKE + 洋葱转发

六项论文创新

每项机制都对应无人系统部署中的一个具体风险，并能落到同一条数传、图传和转发工作流中。

CONTINUOUS SECURITY

五环连续安全链

以设备、身份、密钥、数据、路径五个安全条件串联状态机；前一阶段未通过，后续密钥协商和载荷传输不会启动。

TEE -> SRP-PAKE -> X3DH -> 数据保护 -> 路径保护
STATE BINDING

认证结果绑定身份材料

SRP-PAKE 生成的 K_SRP 用于保护 X3DH 身份公钥和预密钥束，使正确口令、身份密钥与最终会话密钥形成连续约束。

未完成 SRP 认证，X3DH 身份材料不进入明文交换
PATH FIRST

先建路径，再承载握手

多基站场景先由 VRF 选路、每跳 AKE 建立密钥与洋葱电路，再在其中执行四阶段握手，避免中继直接看到认证协商材料。

VRF 选择 + 本跳密钥 + 端点预保护 K_EO
PATH-BOUND DATA

路径绑定的双层保护

端点密钥 K_X3DH 保护业务明文，K_path 再绑定电路编号和路径承诺。路径切换后，外层保护上下文必须重新派生。

K_path = HKDF(K_X3DH, cid, path_commit)
HYBRID RELAY

弱覆盖下的混合安全接力

将基站、无人机与地面机器人统一纳入候选图，综合可达性、带宽、时延、丢包、电量、可信度和节点类型选择安全可达路径。

固定节点优先稳定；覆盖不足时允许移动中继补位
ENGINEERING EVIDENCE

协议机制进入独立节点

数传、图传、目录、地面站和中继被拆为可运行模块。中继仅保存电路号、本跳密钥与下一跳状态，不保存完整路径或端到端密钥。

数传保留 ACK；图传使用低延迟连续发送模式
